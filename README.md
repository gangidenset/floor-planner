# AI Floor Planner

間取り図を読み込み、家具を実寸（cm）で配置し、AI（またはデモモードのルールベース）で家具配置を3パターン提案してもらえる 2D Web アプリです。

## 起動方法

必要なもの：Node.js（v18 以上）

- **Windows**：`start.bat` をダブルクリック（ブラウザで http://localhost:5173 が開きます）
- **コマンド**：このフォルダで `npm start` を実行し、http://localhost:5173 を開く

外部ライブラリのインストールは不要です（PDF読み込み時のみ、pdf.js をインターネットから取得します）。

## スマホで使う（ホーム画面のアプリ）

PWA（ホーム画面に追加できる Web アプリ）に対応しています。スマホではアイコンから全画面で開け、一度開けばオフラインでも起動します。データはその端末のブラウザに保存されます（パソコンとは別。移すときは「その他」→「すべてをバックアップ」と「ファイルを読み込む」）。

- **公開する**：GitHub のリポジトリに push すると `.github/workflows/pages.yml` がアプリのファイルだけを GitHub Pages に公開します（リポジトリの Settings → Pages → Source を「GitHub Actions」に）。公開先の URL をスマホで開き、Android の Chrome は「その他」→「ホーム画面にアプリとして追加」（またはブラウザのメニュー →「アプリをインストール」）、iPhone の Safari は共有ボタン →「ホーム画面に追加」
- **同じ Wi-Fi で試すだけ**：`npm start` したパソコンの IP アドレス（例 `http://192.168.0.10:5173`）をスマホで開く。この場合は https ではないので、ホーム画面への追加とオフライン起動はできません
- 公開先には AI API のサーバーが無いので、AI提案はデモモードで動きます
- スマホでは、家具を選ぶとキャンバス右下に「回転・反転・複製・削除・詳細」のボタンが出ます（キーボードの代わり）。2本指でズーム・移動、壁を描くときは「区切る」で続けて引くのを終えます
- アプリのファイルを追加・削除したら `service-worker.js` の `SHELL` と `CACHE` の番号を更新してください。アイコンは `python scripts/make_icons.py` で作り直せます

## AI API の接続（任意）

APIキーはブラウザには置かず、サーバーの環境変数でのみ扱います。未設定でもデモモードで全機能が動きます。

```bash
npm install @anthropic-ai/sdk
set ANTHROPIC_API_KEY=sk-ant-...   # macOS/Linux は export
npm start
```

- 使用モデルは既定で `claude-opus-5-5`（環境変数 `AI_MODEL` で変更可）
- AI の返答は、デモモードと同じ形式（家具の座標・寸法・角度・理由・メリット・注意点）で受け取り、アプリ側で再検証します
- エラー時は自動的にデモモードで作成します

## 主な操作

| 操作 | 方法 |
|---|---|
| 家具の追加 | 左の一覧をクリック、またはキャンバスへドラッグ（ダイニングテーブルは人数分のダイニングチェアも一緒に置かれます。椅子はテーブルにつながり、テーブルを動かす・回す・複製・削除すると一緒に動きます。テーブルを選んで右パネルの「椅子をテーブルにつなげる」でオン・オフできます。テーブルと椅子を1つの家具として扱いたいときは「ダイニングセット（2人／4人／6人／丸・4人）」を、ソファとセンターテーブルなら「リビングセット（2人掛け／3人掛け＋テーブル）」を、ベッドとナイトテーブルなら「ベッドセット（シングル／セミダブル＋1台、ダブル＋2台）」を使います） |
| 移動 | ドラッグ（グリッド・壁にスナップ、Alt で解除）／矢印キー 1cm（Shift で 10cm） |
| サイズ変更 | 四隅・辺のハンドル、または右パネルの数値入力 |
| 回転 | 上の丸ハンドル（15°刻み、Shift で 1°）、R キーで 90°、右パネル |
| ビーズクッション | 「ソファ」の「ビーズクッション（ヨギボー Max／Midi／Mini など）」。大きさは寝かせて置いたときの目安なので、使い方に合わせて右パネルで調整してください |
| ロボット掃除機 | 「その他」の「ロボット掃除機（ルンバなど）」と「ロボット掃除機の充電台」。充電台は背面を壁に付け、前に約50cmの空きがないとチェックで知らせます（本体を充電台の前に置くのはOK） |
| 左右反転 | F キー、または右パネルの「⇋ 左右反転」（ベッドセットのナイトテーブルの側、L字ソファの向きなど） |
| 複数選択 | Shift+クリックで追加・解除、Shift+何もない所をドラッグで範囲選択、Ctrl+A ですべて。選んだ家具はまとめて移動（ドラッグ・矢印キー）・回転（並びを保ったまま）・反転・固定・複製・削除できます |
| 複製・削除 | Ctrl+D ／ Delete |
| 画面操作 | 何もない所をドラッグ、ホイールでズーム、0 で全体表示 |
| 元に戻す／やり直す | Ctrl+Z ／ Ctrl+Y |
| 保存 | Ctrl+S（ブラウザの LocalStorage に保存し、次回起動時に復元） |
| 壁を描く | 右パネル「壁と部屋の区切り」の「✏ 壁を描く」または W キー。始点と終点をクリック（続けてクリックするとつながった壁）。縦横にそろい、グリッド・既存の壁の端・部屋の角に吸い付きます（Alt で縦横にそろえない）。数字を打って Enter でその長さの壁、右クリック・ダブルクリック・Esc で区切り、もう一度 Esc で終了。壁の厚みは右パネルで指定 |
| 部屋を描く | 右パネル「壁と部屋の区切り」の「▭ 部屋を描く」。壁に囲まれた所をクリックするとその範囲を部屋（区切り）にします（ドア・窓の所は閉じているものとして扱います）。ドラッグで長方形の部屋も描けます。名前を付けると、AI提案の「配置する範囲」に使えます |
| 実寸で合わせる | 右パネル「部屋」の「📐 実寸で合わせる」。部屋の横幅・奥行きや「📏 測る」で測った長さに実寸を入れると間取り全体を拡大・縮小（家具の大きさと壁の厚みはそのまま）。ドア・収納扉の幅も測った値にでき、搬入チェックで「確かめた幅」として扱います |
| マイ家具 | 家具ライブラリの「＋ マイ家具を登録」。名前・大きさ・形・色・メモ・お店のURLを登録すると「マイ家具」から置けます（すべての間取りで使え、バックアップにも入ります）。「✎ 編集」で変更・削除。家具リストにメモと URL も出ます |
| 距離を測る | キャンバス下の「📏 測る」または M キーで、測りたい2点をクリック（Shift で縦・横にそろえる、もう一度クリックで測り直し） |
| 家具リスト | 「その他」→「家具リスト（購入リスト・搬入チェック）」。名前・サイズ・個数の一覧を CSV（Excel で開けます）に書き出し・印刷。値段（1つあたり）・購入済みを入れ、予算を入れると合計・購入済み・これから・予算の残りを表示（右パネルの家具の設定でも入力可。マイ家具に値段を登録すると置いたときに入ります） |
| 壁の長さ・厚み | 壁を選んで右パネルの「長さ」「厚み」に数値を入力。「つながった壁も一緒に動かす」がオンなら、端につながった壁とその上のドア・窓も一緒に動きます（左・上の端は固定） |
| 印刷・PDF | 「その他」→「印刷・PDF」。部屋ごとの大きさ（cm・畳）・家具の名前と大きさ入りの間取り図を A4 1枚に。下絵、2ページ目の家具リストも付けられます。PDF は印刷画面で「PDF に保存」 |
| 立体表示 | キャンバス下の「🧊 立体表示」または V キー。斜め上から見た図で、家具を登録した高さで立ち上げて表示（90°ずつ回転、壁の高さ・手前の壁を低くするを切り替え）。窓は水色 |
| 搬入チェック | 家具が玄関と置く部屋のドアを、いちばん薄い向きにして通るかをチェック（有効幅 = 開き戸は幅−5cm、引き戸は開く部分、高さ約200cm）。図面から読み取ったドアは幅が推定なので「情報（要確認）」として表示し、ドアの幅を右パネルで直すと通常のチェックになります |
| バックアップ | 「その他」→「すべてをバックアップ（ファイルに保存）」で、ブラウザに保存した全プロジェクトを1つの JSON ファイルに書き出し。「ファイルを読み込む」でそのファイルを選ぶと復元。7日以上バックアップしていないと起動時にお知らせが出ます |

### 間取り図の読み込み（自動認識）
1. 「間取りを読み込む」で PNG / JPG / PDF を選択
2. 黒い壁から建物の外周・内壁・部屋が自動で認識されます（青い枠は移動・大きさ変更・追加・削除が可能）
3. 「作成する範囲」で **間取り全体**（黒い壁と部屋の区切りを再現）か **選んだ部屋だけ** を選ぶ
4. 物件情報の **専有面積（㎡）**（画面右上の青い枠）を入力するか、基準にする部屋の広さ（**畳** または **㎡**、分からなければ横幅 cm）を入力 →「間取りを作成」（専有面積を入れた場合はそちらが優先。どちらも空欄のまま押すと確認のメッセージが出て、もう一度押すと寸法が目安のまま作成されます）
5. 壁の切れ目から窓・ドアの候補が「（自動）」付きで追加されます（種類と位置を確認してください）
6. 浴槽・トイレ・洗面台・洗濯機置き場・キッチン・WIC のハンガーラックは、部屋の大きさ・色（水まわりの水色、収納の赤など）・図面の記号（浴槽・便器・洗濯機パンなど）から判定され（トイレは便器の記号がある部屋だけ）、「（自動）」付きの家具として置かれます（固定はされないので、ドラッグで動かせます）。部屋名も「浴室」「洗面所」「トイレ」「WIC」になります（違っていたら選んで Delete で削除できます）
7. 図面のドアの記号（扇形）からドアが「ドア（自動）」として置かれます（開く向き・蝶番の側も図面に合わせます。トイレと洗面所のように扇形が重なった2枚のドアも分けて拾います）。引き戸（壁の切れ目の中の平行線）は「引き戸（自動）」、折れ戸（切れ目の脇の Λ・く の字の印）は「折れ戸（自動）」として置かれます（扉の奥が収納・WIC の折れ戸・引き戸は「収納扉（自動）」になります）。足りない戸は右パネルの「＋ ドアを置く」「＋ 引き戸を置く」「＋ 折れ戸を置く」で追加でき、ドアを選ぶと「ドアの開き方」で開き戸・引き戸・折れ戸を切り替えられます

作成すると「認識結果の確認・修正」の画面が開き、ドア・窓・収納扉の種類の変更、名前の変更、設備や部屋の削除をまとめてできます（右パネル「壁と部屋の区切り」の「認識結果を確認・修正」でいつでも開けます）。

間取り全体で作成した場合、内壁はキャンバス上の壁になり（クリックで選択・ドラッグで移動・Delete で削除）、家具が壁と重なるとチェックで警告されます。

### 壁・ドア・窓の編集（右パネル「壁と部屋の区切り」）
- **壁を消す（消しゴム）**：消したい壁の上をドラッグ（クリックで30cm四方）。通路にしたい所を開けられます。終わったら「完了」
- **＋ ドア / ＋ 窓**：付けたい壁の上をクリック。壁の向きに合わせて置かれ、その部分の壁は自動で開きます。ドラッグで壁に沿って移動、右パネルで幅・開く向き・90°回転を変更できますAI提案では「配置する範囲」で部屋を選ぶと、その部屋の中だけに配置します。

壁などを作らず**画像を下絵として使うだけ**なら、自動認識の画面で「画像だけ使う（下絵）」を押します。画像全体が配置範囲になり、その上に家具を置いたり、「＋ 壁」「＋ ドア」「＋ 窓」でなぞったりできます（広さを入力しておけば縮尺も合います。未入力なら後から「縮尺を設定」で合わせられます）。

うまく認識できない図面は「手動で設定する」→ 壁の両端をクリックして実寸を入力（縮尺設定）→ 部屋の輪郭をドラッグ、で設定できます。

### 広さ（㎡・畳）の入力
右パネル「配置設定」の「広さ」「畳数」に入力すると、縦横比を保ったまま部屋（と間取り図）の大きさが合わせられます（1畳 = 1.62㎡）。

### AI 提案
右パネル「AI提案」で条件（用途・人数・テイスト・好みの色・所有家具・追加したい家具・重視すること）を指定して実行 → カードでプレビュー → 「この配置を適用する」で**新しいレイアウトとして追加**（元の配置はそのまま残ります）。

## ファイル構成

```
index.html
server.js                 静的配信 + /api/ai-layout（Claude API 呼び出し）
start.bat                 Windows 用起動スクリプト
src/
  main.js                 画面の組み立て・イベント
  state.js                状態管理・Undo/Redo
  canvas.js               SVG キャンバス（ズーム・パン・ドラッグ・リサイズ・回転）
  render.js               シーン描画（キャンバス・サムネイル・PNG 共通）
  furniture.js            家具コンポーネント（上面図 SVG）
  floorplan.js            部屋・ドア・窓、背景画像、縮尺設定
  layout-validator.js     配置チェック（はみ出し・重なり・開口部・使うスペース・動線）
  ai-layout.js            AI 呼び出し（サーバー経由）と結果の正規化
  ai-demo.js              デモモードのルールベース配置生成
  panels.js / ai-panel.js 左右パネル
  actions.js / ui.js      共通操作・モーダル等
  storage.js              LocalStorage / JSON / PNG 書き出し
  data/furniture-library.js  家具ライブラリ
  data/sample-project.js     サンプル LDK（寸法・開口部は架空）
```

家具データ形式（単位 cm、x・y は家具の中心、rotation は時計回りの度、rotation=0 で正面が下向き）：

```json
{ "id": "sofa-001", "type": "sofa-2", "name": "2人掛けソファ", "category": "sofa",
  "x": 150, "y": 200, "width": 160, "depth": 85, "height": 75, "rotation": 0, "color": "#B7A99A" }
```
